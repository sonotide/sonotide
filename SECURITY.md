# Security policy

## Supported versions

Sonotide is currently a pre-1.0 project. Security fixes are provided for the
latest released `0.4.x` version. Users should update to the newest patch release
before reporting a problem or requesting support for a fix.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Use the
repository's **Security** tab to submit a private vulnerability report:

<https://github.com/sonotide/sonotide/security/advisories/new>

Include the affected Sonotide version, Windows version, reproduction steps,
expected impact, and a minimal proof of concept when it is safe to share one.
If private vulnerability reporting is unavailable, contact the repository owner
privately through GitHub before publishing details.

You should receive an acknowledgement through the private report. No fixed
response or remediation deadline is promised while the project is maintained
without a dedicated security team.
